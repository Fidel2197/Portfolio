FortunatoCare

A multi-page healthcare interface with services, doctor profiles, appointment forms, and portal screens.

HTML · CSS · JavaScript · Browser storage

Open app ↗View repository ↗

Learning to organize a larger website

FortunatoCare explores how service pages, doctor profiles, appointment forms, and portal screens fit together. The focus is helping a visitor move between those pages without losing their place, using a consistent layout and navigation.

An interface exercise with clear limits

Appointment and portal flows use browser storage and fictional information. They are not connected to a healthcare provider or a secure medical-record system. This earlier project remains available as part of the progression from static pages toward more complete applications.
