Python + React · Data quality

DataDock

Find missing values and duplicates in CSV files, explore charts, and export a cleaned copy. Accounts keep reports available across devices.

React · TypeScript · FastAPI · pandas · PostgreSQL

Open app ↗View repository ↗

A useful starting point for a messy spreadsheet

A CSV can look ready to use while hiding missing values, repeated rows, or inconsistent columns. DataDock brings those issues into one workspace so someone can inspect the file, explore charts, and choose cleanup steps before exporting a new copy. The original upload stays intact during that process.

From upload to a saved report

The React client sends the file to FastAPI. pandas and NumPy profile its columns and rows, while SQLAlchemy connects report records and ownership to PostgreSQL. The interface turns that analysis into a report a person can act on, rather than asking them to write a script for each file.

Deciding what should load when

The upload screen does not need every chart loaded immediately. Charts load on demand, records are paginated, and cached server state helps avoid unnecessary repeat requests. Those choices keep the initial workflow focused while leaving more detailed exploration available when it is needed.

Errors and report ownership

Malformed files, oversized uploads, and database failures need an explanation the user can work with. Report access is checked against the current account or guest session, and deleting a report removes its stored data. Account-isolation tests check that a report is not exposed to another account.

A change that came directly from feedback

The sidebar once clipped its account controls and made scrolling awkward. Feedback led to a scrollable navigation area, sign-in controls closer to the top, and a collapse button. It is a small-looking change that makes the whole workspace easier to use. API and frontend checks, plus Docker builds in GitHub Actions, support the application beyond its appearance.

What is deployed today

The public app runs on Vercel with Neon PostgreSQL. The repository also includes Docker Compose, Nginx, and AWS deployment configuration for another hosting path. Those configurations are useful implementation work, but they are distinct from the infrastructure serving the current public app.
