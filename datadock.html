DataDock

Find missing values and duplicates in CSV files, explore charts, and export a cleaned copy. Accounts keep reports available across devices.

React · TypeScript · FastAPI · pandas · PostgreSQL

CSV checks

Upload a CSV to check missing values, duplicates, and inconsistent numbers. Filter flagged rows, compare categories in charts, and choose cleanup options before exporting. The original file stays intact.

Cleanup options include trimming spaces and removing exact duplicates or empty rows. Missing values and unusual numbers stay available for review; the app does not fill them in or delete them automatically.

Backend and frontend

React sends CSV uploads to FastAPI. pandas and NumPy analyze the data; SQLAlchemy stores reports in PostgreSQL.

The database keeps the original CSV, its report, and row records. Exports are generated from the original with the selected cleanup options, so trying a different cleanup does not overwrite the source.

Performance

Charts load on demand, tables use paginated records, and TanStack Query caches server data. Search runs on the server rather than downloading every row to the browser.

Analysis runs when the file is uploaded. Later table requests fetch the requested page and filters. Column headers and leading-zero identifiers are preserved in the data.

Accounts and testing

Reports belong to an account or guest session. API routes check ownership, and automated tests cover account isolation, upload validation, and analysis rules. GitHub Actions also checks the frontend and Docker builds.

Signing in can move guest reports into an account. Sessions use HttpOnly cookies and can be revoked. Password recovery uses a one-time recovery code. Tests check that one account cannot open another account’s reports.

Sidebar fix

The sidebar clipped the account controls on shorter screens. I moved sign-in higher, added a collapse button, and fixed the navigation scrolling.

Hosting

The live app runs on Vercel with Neon PostgreSQL. The repository includes alternative Docker Compose, Nginx, and AWS configurations; the AWS setup has not been deployed.
