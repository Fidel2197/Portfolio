Cowboy Online Bookstore

A team bookstore application with a searchable catalog, stock-aware orders, and server-calculated totals.

React · TypeScript · Django REST · PostgreSQL

Open app ↗View repository ↗

My contribution

I contributed workflow diagrams and requirements, then implemented cart and wishlist management, the checkout/payment interface, order confirmation, and related storefront state. The merged pull request includes frontend tests and documents test, TypeScript, and production-build checks.

The team application

The React and TypeScript storefront connects to a Django REST API and PostgreSQL. Visitors can search a 36-item catalog, save products, and submit orders. The server checks stock and calculates totals.

Orders

Checkout records a pending pickup or delivery request. Payment collection and fulfillment tracking are not connected. This is a collaborative course project.
