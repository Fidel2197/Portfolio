Cowboy Online Bookstore

A team bookstore application with a searchable catalog, stock-aware orders, and server-calculated totals.

React · TypeScript · Django REST · PostgreSQL

Open app ↗View repository ↗

My contribution to the team project

My documented course contribution focused on workflow diagrams and testable requirements for registration, search, checkout, sessions, and administration. That work helped describe how the pieces should fit together and what a successful interaction should do. This is the same contribution highlighted on my résumé.

What the application does

The complete project includes a React and TypeScript storefront, a Django REST API, and hosted PostgreSQL. Its searchable catalog contains 36 items, and the server checks stock and calculates order totals. The current portfolio version also includes storefront and API restoration work; those capabilities describe the application as a whole, not a claim that I individually built every part.

Keeping the scope clear

Checkout creates pending orders. The site is a collaborative course project, not a university-operated store or a payment processor. Separating requirements, team contributions, and the delivered application makes it easier to discuss the work accurately.
