Next.js + AI · Food assistant

SnapChef

Turn a food photo into recipe ideas, ingredient suggestions, and nutrition estimates, with saved scans and account history.

Next.js · React · TypeScript · Supabase · AI APIs

Open app ↗View repository ↗

The problem

A food photo is a starting point for a recipe, but people also need ingredient ideas, substitutions, and a way to revisit previous results.

How data moves

The Next.js client sends the image to a server route that calls a configured AI provider. Supabase supplies authentication, scan records, and image storage. Provider keys stay on the server.

Example results and limitations

An example result is explicitly labeled when the app uses its built-in example flow. Photo identification and nutrition values are estimates. The current scan-image storage bucket is public; uploaded image URLs are not private documents.

Engineering improvements

Upload, account, history, and result responsibilities are separated so they can be reviewed and changed independently. The repository documents setup, provider configuration, validation, error handling, and saved-history behavior.
