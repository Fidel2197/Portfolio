Canvas · Puzzle game

Tetris

A browser puzzle game with hold, next preview, a ghost piece, scoring, and keyboard controls.

JavaScript · Canvas · HTML · CSS

Open app ↗View repository ↗

Interaction

The game handles piece movement, collision, line clears, scoring, and level changes in JavaScript. A ghost piece and next preview help players plan.

State transitions

Pause, restart, and quit controls separate active play from menus. Keyboard and touch controls offer different ways to play the same game.
