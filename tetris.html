Canvas · Puzzle game

Tetris

A browser puzzle game with hold, next preview, a ghost piece, scoring, and keyboard controls.

JavaScript · Canvas · HTML · CSS

Open app ↗View repository ↗
  1. 01Move and rotate
  2. 02Clear rows
  3. 03Beat your best score

Game logic

The canvas game loop handles movement, rotation, collisions, row clearing, scoring, and levels. A ghost piece, hold slot, and next-piece preview help players plan their moves.

Controls

Play with keyboard or touch controls. Pause, restart, and quit are available during a game, and localStorage saves the best score.

Teaching connection

I also helped students debug Tetris projects in JavaScript and HTML labs, working through keyboard events, game loops, collisions, and rendering.
