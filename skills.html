The tools behind the work.

I find a skill more useful when I can connect it to a real decision in a project. Here is where these tools show up, along with the parts of the implementation you can inspect.

React and TypeScript

Reusable components, typed props, form state, responsive layouts, and Next.js routes. SnapChef separates upload, account, history, and results; SignalDesk separates dashboard views and state.

Python and data

DataDock uses FastAPI, pandas, NumPy, and SQLAlchemy to validate CSV uploads, profile columns, find duplicates, and generate cleaned exports.

Persistence and APIs

PostgreSQL reports in DataDock, Supabase authentication and scan history in SnapChef, and Django REST in the team bookstore. Browser storage is identified separately from cloud-backed accounts.

Testing and delivery

GitHub Actions, API and frontend tests, Docker builds, and Vercel releases. DataDock includes Docker Compose, Nginx, and AWS/GitLab configuration; its public deployment runs on Vercel and Neon.

Performance and interaction

DataDock uses paginated records, cached server state, and charts loaded on demand. Arcane Duel and Tetris use canvas loops, input handling, collision checks, and explicit game states.

Support and communication

JavaScript and HTML lab support, robotics troubleshooting, and resident support at McNeese. Microsoft 365, written documentation, and organized reporting support that work. See responsibilities and dates.
