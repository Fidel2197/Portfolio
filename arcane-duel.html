Canvas · Gesture combat

Arcane Duel

Draw spells in a browser combat game with health, mana, cooldowns, and difficulty settings.

JavaScript · Canvas · HTML · CSS

Open app ↗View repository ↗

Make the gesture feel like an action

Arcane Duel starts with a simple interaction: draw a spell and see it affect an encounter. Pointer input becomes a spell action inside a canvas game loop, with health, mana, cooldowns, and difficulty shaping what happens next.

Keep the state understandable

Pause, restart, and quit each need a distinct state. Input handling and animation have to agree about whether the player is actively fighting or looking at a menu. That makes this project a concrete place to explore the relationship between controls, feedback, and game rules.

Why it belongs here

The applications above focus on data and workflows. This one shows another side of frontend work: timing, drawing, and direct interaction. It runs in the browser and does not claim a multiplayer backend.
