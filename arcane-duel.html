Canvas · Gesture combat

Arcane Duel

Draw spells in a browser combat game with health, mana, cooldowns, and difficulty settings.

JavaScript · Canvas · HTML · CSS

Open app ↗View repository ↗

Draw to cast

Draw a line, circle, zigzag, or swipe to cast a spell. Gesture recognition uses the pointer path’s shape, speed, and direction. Drawing higher or lower also moves the mage toward that lane.

Combat and controls

The canvas game loop handles projectiles, collisions, shields, and spell effects. Difficulty changes the opponent’s health, timing, and behavior. Players can pause, restart, toggle sound, or return to the menu.
